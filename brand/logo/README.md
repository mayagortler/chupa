# לוגו צ׳ופה

תג עגול עם שיבולת זכריני, השם "צ׳ופה" בכתב ישר ושורת התיאור "עיצוב דיגיטלי לאירועים" בקשת.
כל הטקסט בגופן Assistant (משקל 500) והומר לקווי מתאר, כך שהקבצים נראים זהים בכל מחשב ותוכנה בלי להתקין גופן.

- `svg/` – קבצי וקטור: לדפוס, לבית דפוס, ל-Canva ולאתר. אפשר להגדיל בלי לאבד איכות.
- `png/` – תמונות ברקע שקוף (2000–2400 פיקסלים ברוחב), לשימוש בכל מקום שלא מקבל SVG.
- `web/` – אייקונים לאתר ולדפדפן.

## איזה קובץ לאיזה שימוש

| שימוש | קובץ |
|---|---|
| הלוגו הראשי: הזמנות, מסמכים, חתימת מייל, סימן מים | `chupa-badge` |
| כותרת האתר, כותרות מסמכים, כל מקום רחב ונמוך | `chupa-horizontal` |
| התג בלי טקסט: מדבקות, חותמת על עבודות, כשהשם כבר כתוב לידו | `chupa-badge-notext` (וגם `-mono-terracotta`, `-mono-white`) |
| חותמת בצבע אחד, הדפסה בצבע אחד, הטבעה | `chupa-badge-mono-terracotta` / `-olive` / `-ink` |
| על רקע כהה או על תמונה | `chupa-badge-mono-white`, `chupa-horizontal-mono-white`, `chupa-wordmark-white` |
| השם לבד, כשאין מקום לפרח | `chupa-wordmark-ink` / `-terracotta` |
| תמונת פרופיל באינסטגרם, בוואטסאפ ובפייסבוק | `png/chupa-avatar-1080.png` (נחתך יפה גם לעיגול) |
| אייקון לשונית בדפדפן | `web/favicon.ico`, `web/favicon-32.png` (נבנים מ-`svg/chupa-icon-small.svg`) |
| אייקון במסך הבית בטלפון | `web/apple-touch-icon.png` (180), `web/chupa-icon-192.png`, `web/chupa-icon-512.png` |

## כללים קצרים

- אין למתוח, לסובב או לשנות צבעים בתוך הלוגו. כדי לשנות גודל, משנים את הרוחב והגובה ביחד.
- להשאיר מסביב ללוגו מרווח ריק של לפחות רבע מהרוחב שלו.
- גודל מינימלי: התג המלא לא קטן מ-180 פיקסלים על המסך או 4 ס״מ בדפוס, כי מתחת לזה שורת התיאור נהיית לא קריאה. בגדלים קטנים יותר משתמשים ב-`chupa-icon` או ב-`chupa-horizontal`.
- על רקע בהיר משתמשים בגרסה הצבעונית או בגרסת צבע אחד כהה, ועל רקע כהה בגרסה הלבנה.
