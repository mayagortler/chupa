# האתר של צ׳ופה: עיצוב גרפי ומדיה לאירועים

אתר סטטי (HTML, CSS ו-JavaScript בלבד, בלי התקנות ובלי שרת).

## להפעלה מקומית
פותחים את `index.html` בדפדפן, או מריצים בתיקייה הזו: `python3 -m http.server 8000` ונכנסים ל-http://localhost:8000

## לפני שמעלים לאוויר
1. **`assets/config.js`**: ממלאים את מספר הוואטסאפ (חובה, אחרת ההודעות לא מגיעות אלייך), ואופציונלית קישור לאינסטגרם ולתנאי העבודה.
2. עוברים על `CONTENT-TODO.md`: טקסטים ושאלות שחסרים, ומחירים שצריך לאשר.

## מבנה
- `index.html`: דף הבית
- `events.html`: כל האירועים
- `event-*.html`: דף לכל אירוע (הבילדר: סגנון, חבילה או פריטים, מחיר ושליחה בוואטסאפ)
- `assets/data.js`: התוכן והמחירים של כל האירועים (כאן משנים מחירים, סגנונות וחבילות)
- `assets/styles.css`, `assets/app.js`: עיצוב ולוגיקה

## העלאה
כל אחד משירותי האחסון הסטטי מתאים: Netlify (גוררים את התיקייה), GitHub Pages, Cloudflare Pages או Vercel.
