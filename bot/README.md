# בוט הוואטסאפ של צ׳ופה

הבוט שואל את הלקוח את השאלות הראשונות (איזה אירוע, מתי, מה צריך, איזה סגנון), ובסוף שולח למאיה סיכום מסודר בוואטסאפ. האפיון המלא: `../../docs/superpowers/specs/2026-11-21-whatsapp-bot-design.md`.

## לנסות את השיחה בלי Meta
מתיקיית `site`:

```bash
node tests/bot-simulate.js
```

מקלידים מספר כדי לבחור אפשרות, או כותבים טקסט חופשי. בסוף מודפס הסיכום שמאיה הייתה מקבלת.

## מה עורכים איפה
- **שאלות, מוצרים ומחירים**: `assets/data.js`, כמו באתר. הבוט קורא את אותו קובץ, אז אין מה לעדכן פעמיים.
- **הניסוח של הבוט**: `bot/copy.js`. אפשר לשנות טקסטים בלי לגעת בלוגיקה. הגבלות של וואטסאפ: כפתור עד 20 תווים, שורה ברשימה עד 24 תווים. הבדיקות נכשלות אם עוברים אותן.
- **לוגיקת השיחה**: `bot/engine.js`. פונקציה אחת, `step`, בלי רשת.

## קבצים
| קובץ | תפקיד |
|---|---|
| `api/whatsapp.js` | נקודת הכניסה ש-Meta קוראת לה |
| `bot/handler.js` | אימות, מניעת כפילויות, הרצת השיחה, שליחת הסיכום |
| `bot/engine.js` | מנוע השיחה |
| `bot/entry.js` | מזהה הודעה מוכנה מהאתר ומדלג על מה שכבר נענה |
| `bot/summary.js` | הסיכום שנשלח למאיה |
| `bot/meta.js` | שליחה וקבלה מול Meta |
| `bot/store.js` | שמירת השיחה ב-Upstash Redis |

## הקמה (חד-פעמי)
1. ב-[developers.facebook.com](https://developers.facebook.com): חשבון מפתחים, אפליקציה מסוג Business, והוספת המוצר WhatsApp. Meta נותנת מספר בדיקה, ואפשר להתחיל איתו.
2. טוקן קבוע: ב-Business Settings יוצרים System User ומפיקים ממנו טוקן עם ההרשאה `whatsapp_business_messaging`.
3. ב-Vercel, בפרויקט `studiochupa`, מוסיפים את האינטגרציה Upstash Redis (Marketplace). היא מוסיפה לבד את `UPSTASH_REDIS_REST_URL` ואת `UPSTASH_REDIS_REST_TOKEN`. אם השמות אצלכם שונים, מוסיפים אותם ידנית בשמות האלה.
4. ב-Vercel, Settings, Environment Variables:

| משתנה | מה לשים |
|---|---|
| `WHATSAPP_TOKEN` | הטוקן הקבוע משלב 2 |
| `WHATSAPP_PHONE_ID` | ה-Phone number ID מדף WhatsApp, API Setup |
| `WHATSAPP_VERIFY_TOKEN` | מחרוזת אקראית שאת ממציאה |
| `WHATSAPP_APP_SECRET` | App secret מ-App settings, Basic |
| `MAYA_PHONE` | המספר האישי של מאיה, בפורמט בינלאומי בלי פלוס: `972515590208` |
| `SUMMARY_TEMPLATE_NAME` | שם התבנית משלב 6 |

5. ב-Meta, WhatsApp, Configuration: כתובת ה-webhook היא `https://<כתובת האתר>/api/whatsapp`, עם `WHATSAPP_VERIFY_TOKEN`. מנויים לשדה `messages`.
6. תבנית הודעה: בשלב Message templates יוצרים תבנית בעברית, קטגוריה Utility, עם משתנה אחד בגוף ההודעה (`{{1}}`), למשל "פנייה חדשה: {{1}}". זה מה שמאפשר לבוט לשלוח למאיה גם כשעברו יותר מ-24 שעות מההודעה האחרונה שלה אליו. אחרי שמטא מאשרת, שם התבנית נכנס ל-`SUMMARY_TEMPLATE_NAME`.
7. כדי שהבוט יוכל לכתוב למאיה בלי תבנית, מאיה שולחת פעם אחת הודעה למספר הבוט. זה פותח חלון של 24 שעות.

## לפני שמחברים את המספר האמיתי
- בודקים עם מספר הבדיקה של Meta: שיחה מלאה, הודעה מוכנה מהאתר, "מאיה" באמצע השיחה, תמונה במקום טקסט, והודעה אחרי שהשיחה הסתיימה.
- **שאלה פתוחה**: האם אפשר להשתמש במספר 972515590208 גם בבוט וגם באפליקציית WhatsApp Business (Meta קוראת לזה Coexistence), או שצריך מספר נפרד? לבדוק בתיעוד הנוכחי של Meta לפני שמעבירים את המספר, כי העברה עלולה לנתק את האפליקציה.
- המחירים ב-`assets/data.js` הם טיוטה (ראו `CONTENT-TODO.md`), והבוט מצטט אותם.

## בדיקות
מתיקיית `site`:

```bash
for f in bot-engine bot-entry bot-summary bot-meta bot-handler; do node tests/$f.test.js; done
```

## מה לא נבדק עדיין
הבדיקות רצות בלי רשת, עם תחליפים ל-Meta ול-Redis. לא נבדקו מול Meta בפועל: אימות החתימה על הגוף הגולמי ב-Vercel (אם כל בקשה חוזרת 401, זה המקום לחפש), שמות משתני הסביבה שהאינטגרציה של Upstash יוצרת, ואישור התבנית.
